# UNC Table Tennis Club Website

A modern, responsive website for the University of North Carolina Table Tennis Club.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Navigation**: Sticky navbar with smooth scrolling
- **Hero Section**: Eye-catching welcome banner
- **About Section**: Club information and features
- **Schedule**: Practice times and locations
- **Events**: Upcoming tournaments and activities
- **Contact Form**: Easy way to get in touch
- **Social Media Links**: Connect on Instagram, Facebook, and Discord

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features (mobile menu, form handling, animations)

## How to Use

1. Open `index.html` in any modern web browser
2. Navigate through sections using the menu or smooth scroll links
3. Fill out the contact form to reach out to the club

## Customization

Update the following information with your club's details:
- Email address in the contact section
- Practice times in the schedule section
- Event dates in the events section
- Social media links
- Location and other contact information

## Browser Support

- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers
